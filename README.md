# 人工智能训练师理论课试题训练

本项目提供一个基于浏览器的答题页面，用于人工智能训练师理论课的题库练习与模拟考试。页面使用 `questions.js` 中的题库数据渲染判断题与单选题，支持训练模式（即时反馈）和模拟模式（提交后统一评分）。

**主要功能**
- 判断题与单选题练习
- 两种答题模式：训练（即时反馈） / 模拟（提交后评分）
- 分区提交、题号索引、答题统计与结果弹窗
- 题库由脚本生成，可从解析后的 JSON 或 PDF 提取

**项目结构（主要文件）**
- `index.html` — 前端主页面，直接在浏览器打开即可体验
- `questions.js` — 页面加载的题库数据（由解析脚本生成）
- `parsed_questions.json` — 解析/中间数据（可用于编辑题库）
- `parse_questions.py`, `make_questions_js.py`, `extract_pdf.py`, `scan_pdf.py` 等 — 题库解析与生成脚本

（项目中还包含若干辅助脚本：`clean_parsed.py`, `dump_pages.py`, `inspect_questions.py`, `show_near_multi.py`, `test_multi_match.py` 等。）

**本地运行 / 使用**
1. 推荐在项目目录启动本地静态服务器（避免 `file://` 限制）：

```
python -m http.server 8000
```

2. 在浏览器中打开： `http://localhost:8000/index.html` 或直接双击打开 `index.html`（某些浏览器对本地脚本有安全限制，建议用服务器方式）。
3. 页面首次打开会弹出模式选择：选择“训练”或“模拟”后开始答题。

**答题模式说明**
- 训练模式：每题选择后立即显示正误与标准答案，适合练习和记忆。
- 模拟模式：页面会在进入时从题库抽题（示例逻辑：判断题 20 题、单选题 70 题，视题库大小调整），答完后统一提交并展示得分与错题清单。

**如何更新题库**
- 修改 `parsed_questions.json` 或准备新的原始 PDF 后，使用仓内脚本（例如 `make_questions_js.py` / `parse_questions.py`）生成或更新 `questions.js`，然后刷新页面查看变更。

**开发与调试**
- 在 VS Code 中编辑 `index.html`、内联样式或脚本，修改后刷新浏览器查看效果。
- 若需调试跨域或本地加载问题，请通过简易 HTTP 服务运行页面（见上文命令）。
